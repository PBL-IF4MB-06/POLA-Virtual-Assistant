# BAB III PERANCANGAN SISTEM Bab ini menjelaskan perancangan sistem POLA (Polibatam Assistant) yang telah direvisi agar selaras dengan implementasi aplikasi saat ini (versi 1.0.0, App Shell v8). Perancangan mencakup gambaran umum arsitektur, diagram use case, skenario use case, activity diagram, entity-relationship diagram (ERD), serta perancangan antarmuka berbasis screenshot aplikasi aktual.

3.1 Arsitektur Sistem

Aplikasi POLA dibangun dengan arsitektur client–server yang terdiri dari empat lapisan utama:
LapisanTeknologiFungsi
PresentasiFlutter 3.x (Android, Web, Windows)Antarmuka pengguna: Beranda, Chatbot, Kampus, Profil
Logika AplikasiDart (ChangeNotifier/State)AuthState, ChatState, SettingsState, BookmarkState, NotificationState
Backend AINode.js + ExpressEndpoint `/chat`, integrasi Hugging Face Router, basis pengetahuan lokal
DataSharedPreferences + Supabase (PostgreSQL)Riwayat chat lokal; sinkronisasi profil, percakapan, FAQ saat login
Alur umum: pengguna berinteraksi melalui aplikasi Flutter → pesan chat dikirim ke backend AI → backend memproses dengan PolaBot (rule-based + LLM + FAQ) → jawaban dikembalikan ke aplikasi dan disimpan secara lokal maupun ke Supabase jika pengguna login.
