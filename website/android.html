Install POLA di Android

Langkah install APK di HP Android (Samsung, Xiaomi, OPPO, dll.)

  1. Download file POLA-v1.0.0-android.apk dari halaman download.
  2. Buka file APK di HP (via notifikasi download, Files, atau WhatsApp).
  3. Jika diminta, izinkan Install dari sumber tidak dikenal untuk browser atau file manager Anda.
  4. Tap Install dan tunggu selesai.
  5. Buka aplikasi POLA dari layar utama.
Chatbot tidak menjawab? Backend AI harus bisa diakses HP. Untuk build kampus, set URL backend saat build APK (IP server atau URL publik), bukan 127.0.0.1.
